# 0.0.2 — the harness, part 1 — PLANNED

> **Scope:** `harness/run.py` builds one utility and judges one conformance
> case. The per-utility build, the `unit` stage, the `conformance` stage, and
> the case-directory format.

## Decisions taken at planning

- **P-5 — one build per utility, and `--only <name>` builds exactly one.**
  With sixty artifacts the difference between a usable development loop and a
  coffee break is whether the harness rebuilds what did not change.
- **P-6 — the undefined-symbol scan runs on every artifact**, not on one. It is
  what makes "no C, ever" structural, and sixty artifacts is sixty chances for
  a stray symbol.
- **P-7 — a case is a directory, never a script** (PX-023). `cmd` is argv, one
  token per line. Quoting cannot change what is tested and a case cannot
  accidentally test the shell.
- **P-8 — `stdout` is compared byte-exactly; `stderr` by shape.** A diagnostic
  contains a path that varies by machine, so `stderr` is matched against a
  pattern with the utility name and the errno text pinned and the path
  wildcarded. Comparing diagnostics byte-exactly would make every case
  machine-specific; not comparing them at all would let a utility report
  anything.

## Steps

1. `harness/manifest.py` — the manifest, the schema check, the loud refusal.
2. `harness/toolchain.py` — the LLVM 20.1.2 pin, asked of the tools.
3. `harness/build.py` — per utility: `npkc` → `llc` → the ELF undefined-symbol
   scan against the runtime allowlist → `ld.lld`. Rebuild only what changed.
4. `harness/cases.py` — the case-directory reader (V-7), including the `spec`
   requirement for a conformance case and its prohibition for a differential
   one (PX-022).
5. `harness/run.py` — stages, verdicts, `--only`, `--verdicts PATH`.
6. **One real case green**: `true`, with a conformance case asserting exit 0
   and empty output, carrying its citation.

## Acceptance

- [ ] `python3 harness/run.py --only true` builds and judges one utility
- [ ] the undefined-symbol scan fails the **build** on a deliberately
      introduced symbol
- [ ] a conformance case with no `spec` file is refused by name
- [ ] a `cmd` file containing a shell invocation is refused by name
- [ ] artifact size recorded per utility from the first build (B-5)
