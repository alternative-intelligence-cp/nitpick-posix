# 0.0.1 — the catalogue check — PLANNED

> **Scope:** diff `meta/specs/SCOPE.md` §3's table against POSIX.1-2017 XCU's
> own table of contents, utility by utility, and amend the document. Produces
> `tools/catalogue.toml` — the machine-readable form `check_catalogue` reads —
> and seeds `CONFORMANCE.md`'s departure list with real counts.

## Why this is a subcycle and not a paragraph

`SCOPE.md`'s catalogue was assembled from knowledge. **A normative list
assembled from knowledge is the kind of thing that is 95% right and wrong in
the places that matter** — a utility silently omitted is a gap nobody notices
until somebody's script fails, and a utility listed that the standard does not
define is an extension claiming to be conformance.

The document is amended by this check. **The check does not adjust to the
document.**

## Steps

1. **Obtain the list.** POSIX.1-2017 XCU's table of contents. The Open Group's
   published index is the source; record which edition and which date, in
   `meta/research/`, because a later edition adds and removes utilities.
2. **Diff, three ways.**
   - in the standard, absent from `SCOPE.md` → assign an exclusion class
     (`PX-003` … `PX-007`) with a reason, or add it to the working set
   - in `SCOPE.md`, absent from the standard → mark it an extension (`rev`,
     `clear` are the two expected)
   - present in both → confirm the group is right
3. **Record the counts**, replacing `CONFORMANCE.md` §2's approximations with
   measured numbers.
4. **Write `tools/catalogue.toml`**: one entry per utility with its name,
   status (`build` / `exclude` / `extension`), its class where excluded, its
   cycle where built, and the libraries it consumes.
5. **`check_catalogue`** reads it and fails when a directory exists under
   `src/util/` that the catalogue does not name, or the catalogue names a
   `build` entry with no directory past its cycle.
6. **Amend `SCOPE.md`** and record the amendment as a decision if a class
   changed.

## Acceptance

- [ ] every XCU utility accounted for: built, excluded with a class, or an

- [ ] `CONFORMANCE.md` §2's counts measured rather than approximate
- [ ] `tools/catalogue.toml` written and `check_catalogue` reading it
