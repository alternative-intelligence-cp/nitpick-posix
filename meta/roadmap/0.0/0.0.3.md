# 0.0.3 — the harness, part 2 — PLANNED

> **Scope:** the `differential` stage, the self-check that proves the harness
> can fail, and the tree checks.

## Decisions taken at planning

- **P-9 — the reference is discovered, named and version-recorded**, never
  assumed (PX-021). The run prints which binary answered and its version, and a
  verdict file without that line is not a verdict.
- **P-10 — the differential stage is skipped loudly** when the reference is
  absent, naming the binary. A silent skip is a green run on a machine where
  nothing ran.
- **P-11 — a reference disagreement is a finding, not a failure.** Where GNU
  and BusyBox differ, the harness reports it and the case is promoted to a
  spec-derived one (PX-021). The disagreement is the signal that the standard
  is ambiguous there, which is exactly the case worth writing by hand.

## The self-check — six cases

`harness/selfcheck.py` constructs each and requires a **failure**:

1. a conformance case whose `status` is wrong by one
2. a conformance case whose `stdout` differs by one byte
3. a conformance case with no `spec` file
4. a `cmd` file that is a shell invocation
5. a differential case whose reference is missing — must **skip**, and the run
   must say so, not pass
6. a `catalogue.toml` entry marked `build` with no `src/util/` directory

**The self-check runs first in every full invocation.**
